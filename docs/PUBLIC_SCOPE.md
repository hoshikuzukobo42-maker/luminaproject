# 公開範囲

作成日：2026年9月10日。主要な実装状況・速度測定は9月9日までの記録に基づきます。

## 含めるもの

- `lumina_next/` のPythonソースと既存の依存定義。
- `godot/scripts/` のGDScript。バックアップは除外。
- `contracts/` 直下のJSON仕様。製品の実績・証拠フォルダーは除外。
- 視覚・移動・自律接続に関する24試験ファイル。
- 到着証拠のオフライン再生、展示判定、音声起動設定の参照用スクリプト。
- 共通資源管理の1モジュールと、試験で参照するGodot橋渡しの8モジュール。
- 公開用に新しく整理した日本語文書と検査手順。

実装には過去のモデルや旧シミュレーター専用経路、実験用の描画・評価コードが残っています。ファイルの存在は、現在その機能が運転されていることや、そのモデルで最新試験が通っていることを意味しません。

音声起動スクリプトは設定契約を読む試験のために含めています。関連する起動補助スクリプト・モデル・設定は未同梱のため、この公開コピーからの音声サーバー起動手順として実行しないでください。

## 含めないもの

- APIキー、認証情報、実際の環境設定ファイル。
- 実会話、利用者の記憶、個人データ、DB、音声録音。
- 実機の生ログ、観測画像、スクリーンショット、実績レポートの一括コピー。
- モデル重み、音声合成モデル、外部ツール本体、仮想環境、キャッシュ。
- VRM・GLB・Blend・テクスチャ・音声素材などの実体。
- Godotシーン、Godotアドオン、エクスポート済みアプリ。
- バックアップ、AppleDouble、古い差分・作業コピー。

特にアバターや部屋素材は再配布条件を確認してから別途扱う必要があるため、初回公開には含めません。既存スクリプトの素材名・相対参照は残りますが、素材自体はありません。

## 公開用の変更

抽出したソースは、個人の保存先を含む一部の絶対パスを固定の匿名化プレースホルダーへ置き換えています。これは未同梱の評価データや素材を移植したという意味ではありません。該当する過去の評価・プレビュー機能はそのままでは実行できません。

`SOURCE_MANIFEST.json` は抽出ソースの相対パス、サイズ、抽出元ハッシュ、公開版ハッシュ、匿名化の有無を記録します。新規の公開用文書・検査スクリプトは抽出元がないため、この一覧には入りません。

## 検査の限界

公開前に許可リストによる抽出、典型的な機密パターンの検索、独立したコード点検を行います。パターン検索だけではすべての秘密情報や権利関係を保証できません。依存ライブラリや未同梱素材の権利を、この公開版に一括したライセンスとして付与しません。

本体の動作や自動化設定には公開準備のための変更を加えません。公開先に更新する場合も、この選別コピーだけを対象とし、本体ディレクトリ全体をGitへ追加しない運用を想定しています。
